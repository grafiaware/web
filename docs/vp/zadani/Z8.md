# Z8 Přepínače funkcí v konfiguraci site

- **Větev roadmapy:** Z Základ (viz [ROADMAP.md](../ROADMAP.md))
- **Issue:** #40
- **Řešitel:** Claude
- **Stav zadání:** návrh – schválení sloučením PR

## Cíl

Každou novou funkci VP jde v konfiguraci site zapnout a vypnout. Výchozí stav je vypnuto, mimo NajdiSi vždy vypnuto,
takže nedokončené funkce mohou být v `master` bez vlivu na produkci.

## Rozsah

- Patří sem: třída `Application\Feature\FeatureFlags`, volitelná konfigurace `Site\{Site}\ConfigurationFeatures::features()`,
  `ConfigurationCache::features()`, vazba přepínače na routy (`RouteDefinition::$feature`), unit testy.
- Nepatří sem: žádná konkrétní funkce VP, administrace přepínačů v UI.

## Závislosti

Nic.

## Databáze

Bez změn.

## Rozhraní

- `app/Site/NajdiSi/ConfigurationFeatures.php`: `features(): array` — klíč `'vp.<funkce>' => false`.
  Site bez této třídy má všechny funkce vypnuté, ostatní sites se nemění.
- `ConfigurationCache::features()`: pole přepínačů aktivní site (cache).
- `FeatureFlags::fromConfiguration()->isEnabled('vp.losovani')`: zapnuto je jen přesně `true`, neznámý klíč = vypnuto.
- `new RouteDefinition('POST', '/events/v1/…', Ctrl::class, 'akce', MutationResponseMode::…, 'vp.losovani')`:
  při vypnuté funkci se routa nezaregistruje a router vrátí 404 (`RouteCatalogWiring::wire()` přeskočí definici).
- Šablony: `<?php if (\Application\Feature\FeatureFlags::fromConfiguration()->isEnabled('vp.losovani')): ?> … <?php endif; ?>`.

## Přepínač

Mechanismus sám přepínač nemá.

## Akceptační kritéria

1. Routa s `$feature` a vypnutou funkcí se nezaregistruje (404), se zapnutou ano; routy bez `$feature` beze změny.
2. Site bez `ConfigurationFeatures` má všechny funkce vypnuté.
3. Výchozí hodnoty v `ConfigurationFeatures` NajdiSi jsou `false` (hlídá unit test).

## Testy

- Unit: `tests/Unit/Application/Feature/FeatureFlagsTest.php`, `tests/Unit/Application/Api/RouteCatalogWiringFeatureTest.php`.
- Sada unit: 81 testů, 8 chyb jako dosud (stávající, řeší Z7), nové testy zelené.
