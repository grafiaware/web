# Z7 Testy v CI pro pull requesty do master-vp a master

- **Větev roadmapy:** Z Základ (viz [ROADMAP.md](../ROADMAP.md))
- **Issue:** #43
- **Řešitel:** Claude
- **Stav zadání:** návrh – schválení sloučením PR

## Cíl

Každý push a pull request do `master` a `master-vp` spustí unit testy na PHP 8.4; sada `unit` je zelená.

## Rozsah

- Patří sem: oprava stávajících chyb unit testů, GitHub Actions workflow.
- Nepatří sem: integrační testy v CI (potřebují DB s daty → po Z10 anonymizovaných dumpech), phpstan.

## Závislosti

Nic (PES z Packagistu).

## Databáze

Bez změn.

## Rozhraní

- `composer.json`: chyběl PSR-4 `Form\\` → `src/Form` (testy `EntityArrayCopyTest`, `EntityIteratorTest` nenašly `Form\Hydrator`).
- `HtmlMessage`: kontrola kontextu padala na `TypeError` u vnořených polí (rekurze vracela text místo pole) — opraveno,
  chování a texty chyb beze změny; nový test `HtmlMessageContextValidationTest`.
- Testovací data mailových šablon: úspěšné testy používaly prázdné logo, které nová kontrola kontextu správně odmítá → doplněno logo.
- `SendmailMailControlerTemplateTest` (kampaň 2021, chybí šablona `podekovani-odkazy-igelitka2.php`) → `markTestSkipped`, čeká na rozhodnutí.
- `.github/workflows/php.yml`: PHP 8.4 (`shivammathur/setup-php`), `composer validate --strict`, `composer install`, `phpunit --testsuite unit`;
  spouští se pro `master` i `master-vp`.

Není potřeba.

## Akceptační kritéria

1. `vendor/bin/phpunit -c tests/phpunit.xml --testsuite unit` bez chyb (1 přeskočený test).
2. Workflow proběhne zeleně na pull requestu do `master-vp`.
